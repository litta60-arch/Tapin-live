# Tapin-live

Starter scaffold for Tapin-live: a calling app with text messaging, video calling, chat rooms, and live streaming.

This repo contains a FastAPI Python backend scaffold, a docker-compose setup for local/self-hosted development (LiveKit, coturn, Postgres, Redis), and platform example notes for native iOS (SwiftUI) and Android (Kotlin).

See backend/README.md for local development steps.
